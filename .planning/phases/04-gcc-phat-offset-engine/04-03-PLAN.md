# Plan 04-03: Write GCC-PHAT unit tests

## Objective
Validate the GCC-PHAT implementation with deterministic synthetic signals:
known delays, controlled Gaussian noise, and SNR sweeps.  All tests must pass
before Phase 4 is considered complete.

## Background
Unit tests for DSP code should be self-contained (no external test framework)
and reproducible (fixed random seed).  We generate a 1 kHz sine wave, delay it
by a known integer sample count, add scaled Gaussian noise, and assert that the
measured offset is within 1 ms of the ground truth.

## Tasks

### T01: Create `tests/test_gcc_phat.cpp` — test harness
**Action:** Create `tests/test_gcc_phat.cpp` with a minimal harness:
- `#include <cassert>`, `#include <cstdio>`, `#include <cmath>`, `#include <cstring>`, `#include <random>`, `#include <vector>`
- `#include "gcc_phat.h"`
- `int main(void)` that tracks pass/fail counts and prints a summary.
- No external test framework (GoogleTest, Catch2, etc.) — pure standard library.
**File:** `tests/test_gcc_phat.cpp`
**Verification:** File compiles as a standalone executable.

### T02: Implement `generate_sine`
**Action:** Add a helper:
```cpp
static void generate_sine(float *buf, size_t n, float freq, uint32_t fs)
{
    for (size_t i = 0; i < n; ++i) {
        buf[i] = std::sinf(2.0f * static_cast<float>(M_PI) * freq *
                           static_cast<float>(i) / static_cast<float>(fs));
    }
}
```
**File:** `tests/test_gcc_phat.cpp`
**Verification:** Produces a 1 kHz tone at 48 kHz with peak amplitude 1.0.

### T03: Implement `add_gaussian_noise`
**Action:** Add a helper that injects zero-mean Gaussian noise with a target SNR:
```cpp
static void add_gaussian_noise(float *buf, size_t n, float snr_db)
{
    // Compute signal power
    double sig_pwr = 0.0;
    for (size_t i = 0; i < n; ++i)
        sig_pwr += static_cast<double>(buf[i]) * buf[i];
    sig_pwr /= static_cast<double>(n);

    // Generate noise
    std::mt19937 gen(42u);               // fixed seed for reproducibility
    std::normal_distribution<float> dist(0.0f, 1.0f);
    std::vector<float> noise(n);
    double noise_pwr = 0.0;
    for (size_t i = 0; i < n; ++i) {
        noise[i] = dist(gen);
        noise_pwr += static_cast<double>(noise[i]) * noise[i];
    }
    noise_pwr /= static_cast<double>(n);

    // Scale noise to target SNR
    double scale = std::sqrt(sig_pwr / noise_pwr) * std::pow(10.0, -snr_db / 20.0);
    for (size_t i = 0; i < n; ++i)
        buf[i] += static_cast<float>(noise[i] * scale);
}
```
**File:** `tests/test_gcc_phat.cpp`
**Verification:** After calling, signal power / noise power ≈ 10^(snr_db/10).

### T04: Implement `apply_delay`
**Action:** Add a helper that copies `in` to `out` with an integer sample shift:
```cpp
static void apply_delay(const float *in, float *out, size_t n, int delay_samples)
{
    // Zero-initialise output
    for (size_t i = 0; i < n; ++i)
        out[i] = 0.0f;

    if (delay_samples >= 0) {
        // Target lags reference
        for (size_t i = delay_samples; i < n; ++i)
            out[i] = in[i - delay_samples];
    } else {
        // Target leads reference
        int lead = -delay_samples;
        for (size_t i = 0; i + lead < n; ++i)
            out[i] = in[i + lead];
    }
}
```
**File:** `tests/test_gcc_phat.cpp`
**Verification:** `apply_delay(in, out, n, 480)` shifts the sine wave by exactly
10 ms at 48 kHz.

### T05: Write test cases
**Action:** In `main()`, loop over the Cartesian product of:
- **Delays (samples):** `-24000, -12000, -4800, -480, 0, 480, 4800, 12000, 24000`
  (±500 ms, ±250 ms, ±100 ms, ±10 ms, 0 at 48 kHz)
- **SNR (dB):** `10.0f, 20.0f, 30.0f, 40.0f`

For each combination:
1. Allocate `std::vector<float> ref(96000)`, `tgt(96000)`, `delayed(96000)` (2 seconds @ 48 kHz).
2. `generate_sine(ref.data(), ref.size(), 1000.0f, 48000)`.
3. `std::memcpy(tgt.data(), ref.data(), ref.size() * sizeof(float))`.
4. `add_gaussian_noise(tgt.data(), tgt.size(), snr_db)`.
5. `apply_delay(tgt.data(), delayed.data(), tgt.size(), delay_samples)`.
6. Call `estimate_offset(ref.data(), delayed.data(), ref.size(), 48000)`.
7. Compute `expected_ns = delay_samples * 1e9f / 48000.0f`.
8. Assert:
   ```cpp
   assert(std::fabs(result.offset_ns - expected_ns) < 1000000.0f); // < 1 ms
   assert(result.confidence > 1.0f);
   ```

After the loops, assert that the **mean confidence at 10 dB** is less than the
**mean confidence at 40 dB**:
```cpp
assert(mean_confidence_10db < mean_confidence_40db);
```

Print `PASS` / `FAIL` per test case and a final summary.
**File:** `tests/test_gcc_phat.cpp`
**Verification:** All 36 (9 delays × 4 SNRs) assertions pass.

## Notes
- **No external test framework:** Using `<cassert>` + `printf` keeps the test
  self-contained and avoids adding dependencies.  If the project later adopts
  GoogleTest or Catch2, these tests can be ported easily.
- **Fixed random seed:** `std::mt19937 gen(42u)` guarantees identical noise
  realisations across runs and platforms, making failures reproducible.
- **Signal choice:** A 1 kHz pure tone is the simplest signal that gives a sharp
  correlation peak.  If accuracy struggles, a chirp or band-limited pink noise
  can be substituted (see 04-RESEARCH.md §3).
- **Memory:** Each test allocates 96 k floats (≈ 384 kB) per buffer.  With a few
  temporaries the test uses < 5 MB — trivial for modern hardware.
- **Platform differences:** `std::sinf` and `std::normal_distribution` behave
  identically across C++11-compliant compilers, so results should be portable.
  If tiny floating-point differences cause a 1 ms threshold breach, raise the
  threshold to 2 ms and document it.
- **Wave assignment:** This plan is in **Wave 2** because it cannot begin until
  both 04-01 (PFFFT linked) and 04-02 (`estimate_offset` implemented) are
  complete.

## Risks
| Risk | Mitigation |
|---|---|
| GCC-PHAT accuracy < 1 ms at 10 dB SNR | Increase FFT size or use chirp signal; threshold can be relaxed to 2 ms if justified |
| `std::normal_distribution` differs across libstdc++ / libc++ | Fixed seed still produces deterministic results per toolchain; CI will flag platform-specific failures |
| CTest does not discover the new test | Ensure `add_test(NAME ... COMMAND ...)` is present |
| Build fails because `pffft` target is not visible in `tests/` | `target_link_libraries(test_gcc_phat PRIVATE pffft)` works because FetchContent makes the target global |

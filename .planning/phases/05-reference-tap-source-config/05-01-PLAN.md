# Plan 05-01: Implement reference_tap.c

## Objective
Create `src/reference_tap.h` and `src/reference_tap.c` containing a thread-safe singleton that manages one global reference-source audio tap. The tap attaches `obs_source_add_audio_capture_callback` to the user-designated source, downmixes incoming PCM to mono, and writes it into a shared `av_sync_ring_t`. All attach/detach operations are protected by a mutex. The tap is initialized in `obs_module_load` and shut down in `obs_module_unload`.

## Background
The reference tap is the "house audio" input for the GCC-PHAT engine (Phase 4). Every per-camera filter instance will read from this same shared ring. Because the ring is SPSC-safe (one producer — the reference tap callback — and one consumer per filter), the ring itself needs no mutex; only the callback attach/detach and the source pointer need protection.

<task id="T02">
<title>Create src/reference_tap.c with static global state and mutex-protected attach/detach</title>
<read_first>
- src/ring_buffer.h (av_sync_ring_create / destroy / write signatures)
- src/av_sync_filter.c (downmix pattern: count planes, average, write to ring)
- 05-CONTEXT.md D-01, D-02 (architecture decisions)
</read_first>
<action>
Create a new file `src/reference_tap.c` with the following design and content:

**Static global state (all file-static, never exported):**
- `static pthread_mutex_t ref_mutex;` — protects all mutable state below
- `static char ref_name[256];` — name of the currently designated reference source
- `static obs_source_t *ref_source;` — pointer to the currently attached OBS source
- `static av_sync_ring_t *ref_ring;` — shared ring buffer
- `static uint32_t ref_sample_rate;` — cached sample rate from obs_get_audio_info
- `static float *ref_downmix_scratch;` — heap-allocated downmix buffer
- `static size_t ref_downmix_capacity;` — capacity in floats

**Internal helper: `reference_audio_callback`**
Signature: `static void reference_audio_callback(void *param, obs_source_t *source, const struct audio_data *audio, bool muted)`

Behaviour:
1. `UNUSED_PARAMETER(param); UNUSED_PARAMETER(source);`
2. If `muted` or `!audio` or `audio->frames == 0`, return immediately.
3. If `audio->frames > ref_downmix_capacity`, return immediately (no ring write; a warning is emitted at a higher layer or via periodic logging).
4. Count active planes exactly as in `av_sync_filter_audio`:
   ```c
   int planes = 0;
   for (int i = 0; i < MAX_AV_PLANES && audio->data[i]; i++) { planes++; }
   ```
5. Downmix to mono into `ref_downmix_scratch`:
   ```c
   const float inv_planes = 1.0f / (float)planes;
   for (uint32_t i = 0; i < audio->frames; i++) {
       float sum = 0.0f;
       for (int p = 0; p < planes; p++) {
           sum += ((const float *)audio->data[p])[i];
       }
       ref_downmix_scratch[i] = sum * inv_planes;
   }
   ```
6. Write to the ring: `av_sync_ring_write(ref_ring, ref_downmix_scratch, audio->frames, audio->timestamp);`

**Public function: `reference_tap_init()`**
1. `pthread_mutex_init(&ref_mutex, NULL);`
2. Query sample rate: `struct obs_audio_info oai; ref_sample_rate = obs_get_audio_info(&oai) ? oai.samples_per_sec : 48000;`
3. Allocate ring: `ref_ring = av_sync_ring_create((size_t)ref_sample_rate * 10, ref_sample_rate);` (10 s capacity, same as per-filter ring)
4. Allocate downmix scratch: `ref_downmix_capacity = (size_t)ref_sample_rate; ref_downmix_scratch = bzalloc(ref_downmix_capacity * sizeof(float));`
5. `ref_name[0] = '\0'; ref_source = NULL;`
6. Return `true`.

**Public function: `reference_tap_shutdown()`**
1. `pthread_mutex_lock(&ref_mutex);`
2. If `ref_source` is non-NULL:
   - `obs_source_remove_audio_capture_callback(ref_source, reference_audio_callback, NULL);`
   - `obs_source_release(ref_source);`
   - `ref_source = NULL;`
3. `av_sync_ring_destroy(ref_ring); ref_ring = NULL;`
4. `bfree(ref_downmix_scratch); ref_downmix_scratch = NULL;`
5. `pthread_mutex_unlock(&ref_mutex);`
6. `pthread_mutex_destroy(&ref_mutex);`

**Public function: `reference_tap_set_source(const char *name)`**
1. `pthread_mutex_lock(&ref_mutex);`
2. If `name` is NULL or `name[0] == '\0'`:
   - If `ref_source` is non-NULL, detach callback and release: `obs_source_remove_audio_capture_callback(ref_source, reference_audio_callback, NULL); obs_source_release(ref_source); ref_source = NULL;`
   - Set `ref_name[0] = '\0';`
3. Else if `ref_source` is already set and `strcmp(ref_name, name) == 0`:
   - No-op (same source).
4. Else:
   - Detach existing source if any (same as step 2).
   - Copy new name: `strncpy(ref_name, name, sizeof(ref_name) - 1); ref_name[sizeof(ref_name) - 1] = '\0';`
   - Look up source: `obs_source_t *new_source = obs_get_source_by_name(name);`
   - If `new_source` is NULL: log `LOG_WARNING` with message `"reference source '%s' not found"`.
   - Else if `!(obs_source_get_output_flags(new_source) & OBS_SOURCE_AUDIO)`: log `LOG_WARNING` with message `"reference source '%s' has no audio output"`; `obs_source_release(new_source);`
   - Else: attach callback: `obs_source_add_audio_capture_callback(new_source, reference_audio_callback, NULL); ref_source = new_source;` (do NOT release new_source here — the callback holds a reference).
5. `pthread_mutex_unlock(&ref_mutex);`

**Public function: `reference_tap_get_ring()`**
1. `pthread_mutex_lock(&ref_mutex);`
2. `av_sync_ring_t *ring = ref_ring;`
3. `pthread_mutex_unlock(&ref_mutex);`
4. Return `ring`.

Note: Include necessary headers: `<obs-module.h>`, `<plugin-support.h>`, `<string.h>`, `<pthread.h>`, `"ring_buffer.h"`, `"reference_tap.h"`.
</action>

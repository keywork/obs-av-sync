# Plan 06-01: Spawn per-filter analysis thread

## Objective
Add a dedicated background pthread to every filter instance. The thread wakes every 500 ms (~2 Hz), copies the most recent 4 seconds of mono audio from both the per-filter ring and the shared reference ring, runs GCC-PHAT to estimate the offset, and logs the raw result. The thread is spawned in `av_sync_filter_create` and cleanly joined in `av_sync_filter_destroy`. When `sync_enabled` is false, the thread sleeps but skips correlation and offset application.

## Background
The analysis thread is the consumer side of the SPSC ring buffers built in Phase 3. It reads via `av_sync_ring_read` (acquire ordering) with per-filter consumer cursors (`ref_cursor` and `src_cursor`). The thread lifecycle is tied to the filter instance: create spawns, destroy signals exit via `thread_running` and joins.

<read_first>

<action>
Add the following static function to `src/av_sync_filter.c` before `av_sync_filter_info`:

```c
static void *av_sync_analysis_thread(void *arg)
{
	struct av_sync_filter_data *data = arg;

	/* Initialize cursors to oldest valid sample. */
	av_sync_ring_cursor_init(data->ring, &data->src_cursor);
	const av_sync_ring_t *ref_ring = reference_tap_get_ring();
	if (ref_ring) {
		av_sync_ring_cursor_init(ref_ring, &data->ref_cursor);
	}

	while (atomic_load(&data->thread_running)) {
		struct timespec ts = {0, 500000000L};
		nanosleep(&ts, NULL);

		if (!data->sync_enabled) {
			continue;
		}

		const av_sync_ring_t *ref_ring_current = reference_tap_get_ring();
		if (!ref_ring_current) {
			continue;
		}

		/* If reference ring changed (source switched), re-init cursor. */
		if (ref_ring_current != ref_ring) {
			ref_ring = ref_ring_current;
			av_sync_ring_cursor_init(ref_ring, &data->ref_cursor);
		}

		size_t n = data->analysis_window_samples;
		size_t ref_read = av_sync_ring_read(ref_ring, &data->ref_cursor,
		                                     data->analysis_ref_buf, n);
		size_t src_read = av_sync_ring_read(data->ring, &data->src_cursor,
		                                     data->analysis_src_buf, n);

		if (ref_read < n || src_read < n) {
			continue;
		}

		gcc_phat_result_t result = estimate_offset(
			data->analysis_ref_buf,
			data->analysis_src_buf,
			n,
			data->sample_rate);

		obs_source_t *parent = data->source ? obs_filter_get_parent(data->source) : NULL;
		const char *parent_name = parent ? obs_source_get_name(parent) : "(unknown)";
		obs_log(LOG_INFO,
			"analysis thread on '%s': raw_offset=%.2f ms confidence=%.2f",
			parent_name,
			result.offset_ns / 1.0e6f,
			result.confidence);
	}

	return NULL;
}
```

Key behaviours:
1. Cursors are initialized once before the loop.
2. `nanosleep` sleeps 500 ms between iterations.
3. If `sync_enabled` is false, the thread continues the loop without reading rings or calling `estimate_offset`.
4. If the reference ring is NULL (no reference source attached), the iteration is skipped.
5. If the reference ring pointer changes (source switched), the reference cursor is re-initialized.
6. If either ring has fewer than 4 seconds (`n` samples) available, the iteration is skipped.
7. The raw offset (converted from ns to ms) and confidence are logged at `LOG_INFO`.
